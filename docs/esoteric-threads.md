# Threads эзотерика (@evgeniy.mayatnik) — ветки постов

Канал: Buffer #2, service `threads`, аккаунт `--account 2`.
Тема: биоэнергетика, маятник, поле по фото, родовые программы, полевые вирусы.
Голос: короткие фразы, симптом отдельно от причины, без «уникальных методик» и
обещаний вылечить. Читатель приходит с «анализы в норме, а мне плохо».

Лимит Threads 500 символов. Ссылок в постах этой ветки нет, при добавлении в
очередь ставить `--allow-no-link`. Линтер `humanizer-ru` ругается на эмодзи в
заголовке — это ожидаемое предупреждение, шаблон его допускает.

## Ветка 1. Выдаём пользу

```
Я ДИКО ИЗВИНЯЮСЬ, НО если вы [привычное действие] и ждёте, что [желаемый результат], это для вас 😅

я сделала [действие] и получила [результат]

Вот [инструкции / шаблоны]:
```

Работает, когда есть готовый разбор: порядок шагов, чек-лист, схема проверки.
Польза должна быть настоящей, иначе ветка читается как прогрев.

## Ветка 4. Настраиваем алгоритмы на ЦА

```
😭ГОСПОДИ, ТРЕДС, пожалуйста покажи это [ЦА], которые хотят [желание], но [боль / препятствие]!!
```

Дальше 2-3 строки на узнавание боли. Эмодзи в начале обязателен, он и цепляет
ленту. Хэштегов не добавлять.

## Ветка 6. Неприятная правда

```
МНЕ НЕ ХОЧЕТСЯ ТЕБЯ ОГОРЧАТЬ, НО
• [простое действие]
• [простое действие]
• [простое действие]
решат большую часть твоих [проблем в нише].
```

Список из 4-6 пунктов, каждый — действие, а не состояние. Точка в конце не нужна,
строка списка заканчивается без знака.

## Ветка 7. Фигни не советуем

```
Если вы хотите [желаемый результат], делайте [это / действие].

(Я [профессия], фигни не посоветую)
```

Одна конкретная рекомендация, без списка. Подпись в скобках — часть шаблона,
без неё ветка теряет смысл.

## Примеры, опубликованные 24.11.2026

- Ветка 4: «покажи это тем, кто хочет наконец высыпаться, но просыпается уже
  уставшим» — усталость как чужое поле, которое тащат годами.
- Ветка 1: «годами сдаёте анализы и ждёте, что найдётся причина» — порядок
  проверка поля → поиск программы → снятие.
- Ветка 6: сон до 23, вода, тишина без телефона, проверка поля раз в месяц,
  закрытые чужие долги.
- Ветка 7: болезнь возвращается, если смотреть только тело.

## Чего не делать

- Не обещать излечение и не отменять лечение: формулировки про причину и симптом,
  не про диагноз.
- Не выдумывать кейсы с цифрами («ушло за 3 сеанса у 200 клиентов»).
- Не ставить ссылки и хэштеги, это органика, а не воронка.
- Не публиковать две ветки подряд в один день: узнаваемость шаблона падает.
